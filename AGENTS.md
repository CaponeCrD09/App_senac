# Agentes
Este projeto é um passaport virtual de um evento que é realizado em uma escola . Os visitantes poderao encontar as oficinas e horarios e escolher participar. O aplicativo deve registratr as oficinas que um visitante paricipou (concluiu) e gerar um relatorio administrativo.

este é um projeto feito em **react** usando **vite** na versao mais recente ele faz o uso de banco de daos do **supabase** e a sua api
